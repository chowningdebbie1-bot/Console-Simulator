# Console Simulator

Welcome to **Console Simulator**! 🖥️

Console Simulator is a fictional interactive simulator that lets you explore different computers, operating systems, consoles, devices, startup experiences, errors, and other technology-inspired experiences — all from a web browser.

## 🚀 Features

* 💻 Computer and operating-system simulations
* 🪟 Windows versions
* 🍎 macOS experiences
* 📱 iOS, iPadOS, and Android-inspired interfaces
* 🎮 Xbox, PlayStation, and Nintendo-inspired experiences
* 🔌 Interactive power buttons
* 🚀 Startup and shutdown sequences
* 🔊 Startup and system sounds
* 🔒 Lock screens and home screens
* ⚠️ Error and recovery simulations
* 🧪 Error Lab
* 🔧 Hardware Lab
* 🔊 Sound Lab
* 📜 Boot Logs
* 🎨 Designer
* 🏛️ Museum
* 💾 Fictional technology and hardware experiences
* 🖥️ Acer Console (1995) simulation
* ❌ Multiple fictional error scenarios

## 🌐 Run It

Console Simulator is made to run directly in a modern web browser.

Open `index.html` to start the simulator.

It can also be hosted using **GitHub Pages** so the simulator can be accessed as a website.

## 🛠️ Built With

* HTML
* CSS
* JavaScript

The project is designed to work without requiring a real operating system, console, or special hardware.

## 📦 Download

You can download the repository and run the simulator locally.

Use **Code → Download ZIP** on GitHub.

After extracting the files, open `wha.html` in a modern browser.

## ⚠️ About the Simulations

Console Simulator is a **fictional simulation project**.

The interfaces and experiences are created for entertainment and experimentation. They are not intended to reproduce or replace the actual operating systems, consoles, or devices they are inspired by.

## 📜 Project

Console Simulator is an ongoing project. New simulations, devices, errors, interfaces, and features may be added over time.

**Have fun exploring the simulator!** 🖥️🎮
